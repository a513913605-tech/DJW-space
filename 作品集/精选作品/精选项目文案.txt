1. DADA 梦工厂

项目定位：
DaDa 宣发视觉 / 创意合成 / 插画 / 3D

项目背景：
项目基于 DADA 旅行主题 IP 故事展开，需要为 IP 设计一组具有世界观感的宣发视觉物料，让角色不只停留在单一形象展示，而是进入一个可被想象和延展的叙事场景。

我的职责：
参与创意设定、视觉合成、插画与 3D 视觉呈现，完成核心宣发海报及相关物料画面。

业务目标：
通过更完整的故事化视觉包装，提升 DADA IP 的内容吸引力和传播记忆点，为后续系列化物料和产品延展建立视觉基础。

设计目标：
建立一个能代表“旅行、探索、未知”的核心视觉符号，让观众通过“时光机”快速进入 DADA 的故事世界。

设计思路：
以“时光机”作为核心符号，将铅笔的探索属性转译成机械装置。画面通过工作室场景、零件拆解、包装展示和强烈红色识别，营造“产品真实存在”的沉浸感。

关键产出：
DADA TIME MACHINE 宣发主视觉、产品拆解图、包装视觉、场景合成海报。

2. Edgar Plans × NBA 万象天地艺术展

项目定位：
跨界艺术展宣发视觉 / 城市活动营销

项目背景：
项目结合 Edgar Plans 艺术 IP 与 NBA 篮球文化，在 NBA 75 周年节点进行线下艺术展传播，需要将艺术展、篮球精神和城市活动信息整合到同一套传播视觉中。

我的职责：
负责活动宣发视觉的创意构图、画面合成与视觉延展，配合展览主视觉及城市系列传播物料输出。

业务目标：
提升线下艺术展的活动关注度与到场兴趣，让跨界合作在城市空间和社交传播中形成更强的识别度。

设计目标：
让艺术家 IP 与 NBA 竞技感在画面中自然结合，同时保证展览信息清晰、主题明确、第一眼有冲击力。

设计思路：
以“GAME ON”为核心传播语，将角色置入篮球赛场和城市空间。画面用电影海报式构图、强光源和对抗关系强化视觉冲击，同时保留艺术 IP 的童真与荒诞感。

关键产出：
悬念预告海报、主视觉海报、城市系列海报、线下展览传播物料。

3. 腾讯游戏｜欢乐斗地主王炸节

项目定位：
游戏活动营销视觉 / 宣发海报

项目背景：
项目围绕欢乐斗地主“王炸节”活动展开，是一次面向玩家的节日化运营传播，需要通过新的视觉包装激活用户参与，并延续斗地主 IP 的活动影响力。

我的职责：
参与活动主视觉创意、角色合成、插画视觉与多尺寸宣发物料延展。

业务目标：
提升活动点击、参与和转化，让“王炸节”成为用户可感知、可记忆、可持续运营的游戏活动节点。

设计目标：
强化“王炸节”的节日感、玩法特征和年轻化气质，让用户第一眼识别活动主题，并感受到热闹、轻松、带有冲击力的游戏氛围。

关键产出：
活动主视觉、宣发海报、多尺寸推广图、角色局部延展物料。

春节活动视觉 / 游戏化运营传播

5. 招商银行｜官方微博运营

品牌社交媒体运营视觉 / 金融内容插画体系

关键产出：
微博日历视觉、热点运营图、节日海报、金融科普图、公益内容视觉、栏目化模板。
