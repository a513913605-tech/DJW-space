# AI 画板工作流模块

这是个人网站里的低保真 AI 工作流画板原型，方向类似 LibTV / Lovart 的节点式 AI 创作画布。

## 当前框架

- 顶部栏：站点签名、流程标题、站点导航、预览与生成入口
- 左侧工具栏：选择、图片、提示词、模型、连接工具占位
- 中央画布：节点、连线、缩放控制和可横向浏览的大画布
- 右侧参数面板：节点名称、AI 操作、提示词草稿、基础参数
- 节点类型：输入素材、提示词、图像模型、局部重绘、图片融合、人工筛选、输出画面

## 预览

打开：

```text
workflow-module/index.html
```

或通过本地预览服务访问：

```text
http://127.0.0.1:8077/workflow-module/index.html
```
